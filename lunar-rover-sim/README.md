# Lunar Rover Sim

Браузерный симулятор лунохода: ровер Perseverance едет по процедурно сгенерированной лунной поверхности. Рельеф и камни строятся из шума и функций кратеров, без готовых примитивов в итоговой картинке. Освещение подобрано под Луну: чёрное небо, низкое Солнце, резкие тени и характерное для реголита обратное рассеяние.

## Запуск

```bash
cd lunar-rover-sim
npm install
npm run dev        # http://localhost:5173
# production-сборка:
npm run build      # → dist/, можно раздавать любым статическим сервером
npm run preview
```

Нужен браузер с WebGL2 и `EXT_color_buffer_float`: Chrome, Edge, Firefox или Safari 16.4 и новее, с включённым аппаратным ускорением. Открывать `index.html` напрямую из файла нельзя, нужен HTTP-сервер.

## Управление

| Клавиши | Действие |
| --- | --- |
| W / ↑, S / ↓ | ход вперёд / назад |
| A D / ← → | поворот; без газа — разворот на месте |
| Shift | ускорение ×2 |
| Пробел | тормоз |
| C | камера: сопровождение → орбита → Mastcam‑Z → кино |
| T | ход лунного времени: пауза / ×1 / ×1000 / ×10⁴ / ×10⁵ |
| Мышь (перетаскивание), колесо | обзор и зум |
| R | вернуть ровер на колёса |
| G / H | настройки / помощь |
| P | скриншот в PNG |

На сенсорных экранах появляется виртуальный джойстик.

В настройках можно выбрать пресет качества (низкое, среднее, высокое, ультра), выставить лунное время суток и скорость его хода. Там же настраиваются экспозиция, скорость ровера (от реальной 0,042 м/с до «ралли») и отдельные эффекты. Выбор сохраняется в `localStorage`. Качество также задаётся параметром URL: `?q=low|medium|high|ultra`.

## Что внутри

**Рельеф** (`src/terrain`)
- Высоты запекаются на GPU фрагментными шейдерами (`glsl.js`) в несколько слоёв:
  - макрокарта 4×4 км с шагом 2 м: холмы, массивы на горизонте и шесть масштабов кратеров от 5 до 600 м;
  - дальняя карта 32×32 км для горизонта;
  - тайлящийся слой мелкого рельефа 128 м (кратеры 0,2–15 м), который накладывается дважды с поворотом и масштабом, чтобы не было видно повторов;
  - микротекстура реголита (комья и гравий) для нормалей и альбедо.
- Каждый кратер задаётся профилем с валом, выбросами и дном. Молодые кратеры глубже, с острым валом и светлыми выбросами, старые сглажены.
- Сетка поверхности — квадродерево LOD на инстансинге: одна сетка 64×64 с «юбками», смещение вершин считается в вершинном шейдере через бикубическую выборку. Учтена кривизна Луны (R = 1737 км).
- Для CPU (физика, расстановка камней, отсечение) карты высот считываются обратно и сэмплируются теми же формулами, что и на GPU.

**Свет и тени**
- `SunLight` из three.js r186 с двумя каскадами теней вблизи. Для дальних теней от гор карта высот трассируется к Солнцу (`ShadowBaker.js`). Полутень считается по реальному угловому размеру Солнца, 0,53°.
- Грунт отражает свет по фотометрической модели лунного Ламберта (McEwen) с оппозиционным эффектом.
- Отражения на ровере дают окружение из чёрного неба и подсвеченного реголита.

**Камни** (`src/rocks`) — это многогранники из случайных секущих плоскостей со скруглёнными гранями, выветриванием шумом, сколами и плоским основанием. Используются 8 форм с 4 уровнями детализации. Размеры распределены по степенному закону. Больше всего камней в выбросах свежих кратеров.

**Лунное время и небо** (`src/sim/LunarClock.js`, `src/render/Sky.js`)
- Площадка на 26° с. ш. Лунные сутки длятся 29,5 земных дня, на площадке 24 «лунных часа». Солнце идёт по небу с востока на запад, тени от горизонта пересчитываются по кусочкам в фоне.
- Ночью светит только Земля. Она почти неподвижна в небе, её фаза противоположна фазе Солнца, а земной свет освещает грунт голубоватым светом. Экспозиция камеры подстраивается к освещённости.
- Звёзды точечные, без мерцания, с цветовой температурой. Есть Млечный Путь с пылевыми прожилками и пять планет на эклиптике: Венера, Юпитер, Марс, Сатурн, Меркурий. Небосвод вращается вместе с лунными сутками. Днём звёзды тусклее, а у Солнца их гасит блик.

**Энергия** (`src/sim/PowerSystem.js`, `src/rover/SolarArray.js`)
- Солнечная батарея на мачте: два крыла по 1,3×0,92 м с GaAs-элементами под покровным стеклом. Карданный подвес по двум осям сам разворачивает её к Солнцу.
- Выработка: 1361 Вт/м² × КПД 29% × косинус угла падения × видимость солнечного диска. Видимость считается трассировкой рельефа к Солнцу, поэтому в тени кратера или гребня выработка падает.
- Потребление: электроника, обогрев (ночью заметно больше) и приводы; на подъёмах приводы тратят больше.
- Батарея 4 кВт·ч. Ниже 8% ход ограничен, при 0% ровер стоит. Баланс считается в реальном времени, ускоряется только движение Солнца.

**Ровер** (`src/rover`)
- Модель NASA/JPL Mars 2020 Perseverance, public domain, из [NASA-3D-Resources](https://github.com/nasa/NASA-3D-Resources). Сжатие Draco снято при подготовке.
- Мачта с Mastcam‑Z раскладывается при загрузке.
- Колёса и подвеска разрезаны на шарнирные части: балансиры rocker и bogie, поворотные узлы и вращение колёс.
- Физика:
  - кинематика rocker-bogie по опорным точкам колёс на грунте и камнях, с дифференциалом;
  - пружинный или баллистический фильтр в лунной гравитации 1,62 м/с², поэтому на гребнях ровер отрывается от грунта;
  - сцепление ограничивает поворот на скорости, на крутых склонах колёса проскальзывают;
  - крупные валуны работают как препятствия.

**Эффекты**
- Колея с протектором рисуется в тороидальную текстуру вокруг ровера и превращается в микрорельеф грунта.
- Пыль из-под колёс летит по чистым параболам, как в вакууме.
- Постобработка: N8AO, bloom, ACES, SMAA, зерно и виньетка.
- Земля в небе с правильной фазой и опциональные звёзды.

## Структура

```
src/
  main.js              сборка сцены, цикл симуляции, пресеты качества
  terrain/             генерация, выборка, LOD-меш, запекание теней
  rocks/               процедурные камни и их размещение
  rover/               модель + риг подвески, физика
  fx/                  колея, пыль
  render/              небо, постобработка, лунная модель освещения
  core/                камера, ввод
  ui/                  HUD, миникарта, настройки
public/models/         perseverance.glb
```
